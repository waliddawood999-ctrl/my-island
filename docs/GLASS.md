# GLASS — نموذج الزجاج الحقيقي (T04)

> مادة أصلية واحدة × أسلوبان + تراكب CSS رفيع. الكود: `src-tauri/src/backdrop.rs` · `src/pages/island/useBackdrop.ts` · `src/pages/island/island.css` (كتلة «المادة») · `src/appearance.ts`.

## النموذج

**مادة واحدة: أكريليك ويندوز الأصلي** — `SetWindowCompositionAttribute(ACCENT_ENABLE_ACRYLICBLURBEHIND)` على نافذة `main`. هو الآلية الوحيدة التي تمزج سطح المكتب خلف نافذتنا
غير النشطة (`WS_EX_NOACTIVATE | TOOLWINDOW`)، ويبقى مرسومًا والنافذة غير نشطة. نصف قطر التمويه ثابت من النظام (لا يُضبط).

**أسلوبان = خريطتا ألفا الصبغة فقط** (`backdrop.rs::style_alpha`، مرآتها `appearance.ts::styleAlpha`)، t = glassTint (0–80):

| الأسلوب | داكن (صبغة سوداء) | فاتح |
|---|---|---|
| Frosted «مثلّج» (`glassStyle=crystal`) | 0.28 + 0.0075·t | min(0.32 + 0.0075·t, 0.92) — صبغة #eceff3 |
| Clear «شفاف» (`glassStyle=clear`) | 0.10 + 0.0050·t | min(0.14 + 0.0050·t, 0.60) — صبغة بيضاء |

الإعدادات المسبقة الأربعة (كلٌّ يرسم فعلًا بشكل مختلف): Frosted (t=45) · Smoked «مدخّن» (crystal، t=68) · Clear (clear، t=25) · Minimal Dark (مصمت). لا `glassBlur/glassSaturation` فيها.

**تراكب CSS فقط:** حدّ 1px (`::before` بقناع mask-composite) + لمعة علوية `inset 0 1px 0` + ظل نص خفيف. لا `background-image`، لا `::after`، لا طبقات إضافية.

## حالات `<html data-backdrop>`

| القيمة | المعنى | سطح الجسم |
|---|---|---|
| `win10` | الأكريليك مطبَّق (كل بناءات ≥ 17134 بما فيها 11) | **شفاف** — الصبغة داخل الأكريليك فلا تظليل مزدوج |
| `pending` (أو غائب) | الزجاج مسموح لكن غير مطبَّق بعد: انتقال (فتح/إغلاق) أو طلب جارٍ | شبه معتم: داكن `rgb(14 15 20/.92)` · فاتح `rgb(236 239 243/.94)` — يتلاشى إلى الشفاف خلال **160ms** عند وصول win10 |
| `none` | غير مدعوم/فشل الأمر، أو «تأثيرات الشفافية» مطفأة في ويندوز | شبه معتم: داكن `.94` · فاتح `.96` |
| `data-fallback="solid"` | Eco / توفير / تقليل الشفافية: الزجاج غير مسموح | الحال نفسه (شبه معتم + حدّ + لمعة) |

**لا ملء منخفض الألفا أبدًا** — كان هو «الورقة الباهتة». Rust يُسقط صبغة الأكريليك عند كل تغيّر شكل (`win::resize_to_island`) فيمرّ العنصر بـ`pending` الشبه معتم ثم يعود `win10`
بعد استقرار الحركة (`ready = settled && !hidden && opacity > 0` — فالشفافية في الراحة/الفتح < 100٪ لا تمنع الأكريليك). تغيّر `glassTint` أو الأسلوب بنفس الهندسة ⇒ تحديث الصبغة فقط في Rust (`set_accent`) بلا مسح ولا وميض.

## لماذا لا هذا؟

- **لا CSS `backdrop-filter`:** WebView2 الشفاف لا يمرّر بكسلات سطح المكتب إلى مُركِّب Chromium، فالمرشّح لا يرى إلا محتوى الصفحة نفسه (WebView2Feedback #4945 — بالتصميم). لذلك حُذف كل `backdrop-filter` من الجزيرة ومنزلقا التمويه/التشبّع (المفتاحان `glassBlur/glassSaturation` باقيان مهجورَين للتوافق).
- **لا Mica ولا DWMSBT_TRANSIENTWINDOW:** مادتا DWM (Mica/Acrylic عبر `DWMWA_SYSTEMBACKDROP_TYPE`) تسقطان إلى رمادي مصمت على النوافذ غير النشطة (انظر window-vibrancy#139 وتوثيق Microsoft Learn لـAcrylic/Mica: «inactive ⇒ solid»). نافذتنا لا تُنشَّط أبدًا ⇒ SWCA فقط.
- **لا مرشّح إزاحة SVG (انكسار «Liquid Glass»):** نفس القيد (لا وصول إلى سطح المكتب) + كلفة إعادة المعالجة كل إطار.

## الاحتياط والأداء

- الفشل/عدم الدعم/الشفافية مطفأة ⇒ `none` ⇒ سطح شبه معتم (لا ملء شفاف). الأكريليك يُسقَط في Eco.
- لا شيء خارج الشكل المستدير: النافذة ثابتة شفافة 800×500 ومنطقتها (`SetWindowRgn`) = شكل الجزيرة الهدف (انظر IPC `report_island_rect`).
- الانتقالات transform/opacity/background-color فقط؛ لا مؤقّتات ولا استطلاع (نداءات عند تغيّر المدخلات).
