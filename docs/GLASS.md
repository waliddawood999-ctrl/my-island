# GLASS — أسلوبا الزجاج (بلوري / شفاف)

> ملخّص البحث والتقنية المختارة لكل أسلوب. الإعداد: `themeMaterial = glass` + `glassStyle = crystal | clear`.
> الكود: `src/pages/island/island.css` (طبقات CSS) · `src/appearance.ts` (متغيرات/إعدادات مسبقة) · `src-tauri/src/backdrop.rs` (DWM).

## ما وجدناه (بحث مختصر)

- **Apple Liquid Glass (HIG «Materials»)**: مادة تكسر ما خلفها (lensing) بدل أن تكتفي بالتمويه، ولمعات سطحية (specular) تتبع مصدر ضوء
  علوي، وتتكيّف الصبغة مع الفاتح/الداكن؛ وللمادة صيغتان: *Regular* (أكثر تعتيمًا وتمويهًا لضمان التباين) و*Clear* (شفافة جدًا وتحتاج
  طبقة تعتيم/scrim خلف النص). المصدر: developer.apple.com/design/human-interface-guidelines/materials.
- **Fluent 2 / ويندوز 11**: *Acrylic* = تمويه خلفية + ضوضاء + صبغة + طبقة luminosity (للعناصر العائمة المؤقتة كالقوائم)، و*Mica* = مادة
  ثابتة تأخذ لون الخلفية للنافذة الأساسية بلا تمويه حي. الجزيرة عنصر عائم ⇒ أقرب إلى Acrylic.
- **تقنيات الويب المفتوحة (liquid-glass CSS/SVG)**: `backdrop-filter: url(#filter)` مع `feImage` + `feDisplacementMap` (وثلاث مرّات بقنوات RGB
  منفصلة للانحراف اللوني). تعمل في Chromium فقط، **ثقيلة** (تُعاد معالجتها كل إطار)، ولا تنكسر إلا ما داخل صندوق العنصر نفسه؛ لا تقتطع
  «الخلفية» خارج صفحة الويب.

## القيد الجوهري في تطبيقنا

نافذة WebView2 شفافة فوق سطح المكتب. **`backdrop-filter` في CSS لا يرى بكسلات سطح المكتب** (ليست جزءًا من مستند الصفحة)، بل ما رُسم داخل
الصفحة فقط. لذلك التمويه الحقيقي لما خلف الجزيرة يأتي من طبقة DWM الأصلية (`SetWindowCompositionAttribute` أكريليك — نصف قطر التمويه ثابت
من النظام ولا يُضبط). وبالتالي مرشّح الإزاحة SVG لا يستطيع كسر سطح المكتب أصلًا، فضلًا عن كلفته ⇒ **اعتمدنا تقريبًا رخيصًا**:
الإحساس بالعدسة/الحافة يُحاكى بطبقات تدرّج ثابتة (لا تُعاد معالجتها)، ولا نستعمل `feDisplacementMap` إطلاقًا.

## 1) «البلوري» Crystal — Liquid Glass

| الطبقة | التنفيذ |
|---|---|
| تمويه خلفي سميك | DWM acrylic (ويندوز ≥1803) + `backdrop-filter: blur(var(--glass-blur)) saturate(..)` فوقه (≤40px، يُخفَّض في Eco) |
| صبغة | `glassTint` ⇒ ألفا الأكريليك (backdrop.rs) أو ألفا الخلفية في الاحتياط |
| حافة تكسير (rim) | `::before` بحدّ 1px من تدرّج عمودي (ساطع أعلى ← خافت ← ساطع أسفل قليلًا) بقناع `mask-composite: exclude` |
| لمعة سطحية (specular) | `::after`: إهليلج أبيض ناعم أعلى الحبة + خط 1.5px علوي |
| توهّج داخلي وعمق | `box-shadow` داخلي: `inset 0 0 18px` أبيض خفيف + `inset 0 -14px 28px` أسود خفيف |
| لمعان لوني على الحواف | تدرّج مخروطي/خطي سماوي←وردي بألفا ≤ .10 على الحافة فقط (بديل رخيص للانحراف اللوني RGB) |
| النص | `text-shadow` خفيف + صبغة ≥ .62 فوق الأكريليك ⇒ تباين ≥ 4.5:1 حتى فوق خلفية بيضاء/سوداء (يُتحقق في `scripts/glass.test.mjs`) |

## 2) «الشفاف» Clear

| الطبقة | التنفيذ |
|---|---|
| لا تمويه DWM | النافذة الشفافة تُظهر سطح المكتب بوضوح؛ طبقة DWM تمويهها ثابت وكبير فلا تناسب 4–8px ⇒ **لا تُطلب** في هذا الأسلوب |
| تمويه الصفحة | `blur(4–8px)` على ما داخل الصفحة فقط (غلاف الميديا/الطيف) |
| صبغة خفيفة | ألفا .06–.20 من `glassTint` |
| حدّ | 1px واضح: `rgb(255 255 255 / .35)` أعلى ← `.08` أسفل (فاتح/داكن مشتقّان) |
| لمعة | تدرّج علوي ناعم بدون توهّج داخلي ثقيل |
| scrim للنص | طبقة تدرّج داكنة (فاتحة في الوضع الفاتح) داخل الخلفية نفسها خلف الوسط حيث النص، + `text-shadow` ⇒ تباين ≥ 4.5:1 فوق الأسوأ (أبيض نقيّ في الداكن / أسود نقيّ في الفاتح) والمتوسط (مقيس: 4.84 داكن، 8.43 فاتح عند الإعداد المسبق) |

## الاحتياط والأداء

- Eco / وضع توفير البطارية / «تقليل الشفافية» (تفضيل النظام `EnableTransparency=0` أو `prefers-reduced-transparency`): تُسقَط طبقة DWM
  وتصبح الخلفية **سطحًا مصبوغًا شبه مصمت** بنفس الأسلوب (rim + لمعة بلا blur).
- لا شيء خارج الشكل المستدير: `html/body/#root` شفافة، النافذة شفافة، منطقة DWM كبسولة بحجم النافذة وتُسقَط قبل أي تغيير حجم (win::resize_to_island).
- التمويه ≤ 40px، والانتقالات على `transform/opacity` فقط عدا فتح اللوحة (تحوّل الحجم الصريح الوحيد).
- لم نستطع قياس وميض/تأخّر السحب على ويندوز فعليًا من بيئة Linux السحابية؛ المسار الأصلي لم يُغيَّر إلا بفحص EnableTransparency.

## القياس (scripts/appearance.test.mjs)

تباين النص فوق السطح المركّب (الأسوأ / المتوسط، القيم عند الافتراضي والإعدادات المسبقة): بلوري داكن tint45 **6.14 / 13.0** · tint38 **5.03 / 11.8** ·
بلوري فاتح tint45 **7.01 / 11.5** · tint38 **5.99 / 10.8** · شفاف داكن tint14 **4.84 / 11.6** · شفاف فاتح tint14 **8.43 / 13.1** (الحدّ AA = 4.5).
خفض المنزلق `glassTint` إلى قيم منخفضة جدًا (قرار المستخدم) قد ينزل دون AA فوق خلفية متطرفة؛ الافتراضي والإعدادات المسبقة مضمونة.

## تصحيح T02 — «ورقة باهتة ثانية» فوق الزجاج
السبب: تراكب طبقات فوق الأكريليك الأصلي — تدرّج أبيض على جسم الحبة + `::after` (لمعة إهليلجية + لمعان لوني) + بطاقات داخلية بتدرّج و`backdrop-filter` — فيبدو السطح حليبيًا. الآن لكل أسلوب **سطح واحد**: (أكريليك أصلي أو صبغة CSS) + حدّ 1px (`::before`) + لمعة علوية `inset` رفيعة؛ والبطاقات الداخلية مسطّحة. «الشفاف» صبغة مسطّحة واحدة بلا تمويه (لا يرى سطح مكتب أصلًا)، فصفحة الإعدادات تخفي منزلقي التمويه/التشبّع له. القياس: شفاف داكن 3.04:1 فوق الأبيض النقي و8.84 فوق المتوسط؛ شفاف فاتح 4.79/10.40.
