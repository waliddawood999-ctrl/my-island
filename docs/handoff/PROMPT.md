# برومت التسليم الكامل — MyIsland (انسخه كما هو لأي AI برمجي)

أنت تعمل على مشروع **MyIsland**: تطبيق «Dynamic Island» لويندوز (Tauri 2.12 + Rust + React 19 + Vite + Tailwind v4). المالك لا يتسامح مع التداخل في الواجهة، ولا مع الأخطاء الجديدة، ولا مع أي تنفيذ خارج المطلوب. التزم بكل ما يلي حرفيًا.

## 0) قواعد ملزمة
1. اقرأ أولًا: `AGENTS.md` و`CLAUDE.md` و`docs/handoff/HANDOFF.md` و`docs/STATUS.md`. قواعد المشروع فيها أعلى من أي اجتهاد منك.
2. **الصور في `docs/handoff/` هي المرجع البصري الملزم.** افتحها وانظر إليها فعلًا قبل كل مهمة (إن لم تستطع رؤية الصور فأخبر المالك فورًا ولا تخمّن الشكل). التنفيذ يطابقها بالضبط: الترتيب، الأحجام النسبية، الألوان، وعدم التداخل. لا تضف عناصر غير موجودة فيها ولا تحذف موجودًا.
3. **مهمة واحدة = commit واحد = اختبار قبل الانتقال.** لا تجمع مهمتين في تغيير واحد.
4. **لا تغيّر ألوان أو بذور أي ثيم قائم**، ولا مفاتيح الإعدادات الموجودة، إلا ما تطلبه المهمة صراحة. أي مفتاح جديد يُضاف في `src/settings.ts` و`src-tauri/src/state.rs` (DEFAULTS) و`src/appearance.ts` (قوائم المفاتيح/التحقق)، وأي تغيير في قاعدة البيانات يكون بترحيل مرقّم.
5. كل نص واجهة عبر `i(ar, en)`. لا ملفات خطوط. الحركة عبر `src/motion.ts` ومكتبة motion فقط.
6. **لا تدفع مباشرة إلى `main`.** فرع عمل ثم PR ثم دمج.
7. عند خطأ بناء: 3 محاولات مختلفة كحد أقصى، ثم توقف واعرض الخطأ كما هو.

## 1) الحالة الحالية (لا تعد عمل ما أُنجز)
**منجز ومدمج في main:** إزالة `SetWindowRgn` وفرض شفافية WebView2 · الدوك (5 صفحات) والتخطيط العريض الأولي · الساعة الحرة · مصغّرة المشغّل بحجم الجزيرة (`src/pages/island/thumbSize.ts`) · الثيمان الافتراضيان (`ivory` فاتح، `noir-gold` داكن) · الهالة `box-shadow` بدل القناع · حذف الألوان المسجّلة · النمط فاتح/داكن فقط · التبويبات دوك/مخفية فقط · مفتاح التبديل الواضح بالوضع الفاتح · تنقل العجلة بترتيب الدوك.

**جرى التراجع عنه عمدًا (ويُنفَّذ ضمن المهام أدناه بحذر):** معرض الثيمات المسطّح، حذف «تعيين الحزمة»، مادتان فقط، إعداد شكل شريط التقدم.

## 2) أولًا — أصلح بلاءً مفتوحًا قبل أي ميزة (المهمة 0)
**بلاغ المالك:** «بعد التحديث الأخير الجزيرة تختفي فجأة ولا تظهر حتى مع تمرير الماوس». لم يُعرف السبب بعد، ولم يُعثر عليه بقراءة الفرق. المطلوب:
1. قارن `git diff` بين آخر إصدار كان سليمًا (1.0.73) وآخر `main`، وركّز على: `src/pages/island/Halo.tsx` و`island.css` (`.island-halo`) و`useSettings.ts` و`Pill.tsx` و`src-tauri/src/hit.rs` و`fullscreen.rs` و`backdrop.rs` و`win.rs`.
2. افحص سيناريوهات: الاختفاء بعد تشغيل فيديو/ملء شاشة (`hideInFullscreen`)، الإعدادات المحفوظة القديمة (`panelTabsStyle` بقيم قديمة، `themeMode` القديم `system|sun`، `glassStyle: clear`)، حالة `set_ignore_cursor_events` العالقة، وانهيار React بدون ErrorBoundary (أضف ErrorBoundary يعيد رسم الجزيرة بدل شاشة فارغة).
3. اكتب اختبار انحدار يعيد المشكلة إن وجدتها (Playwright مع `scripts/mockBridge.cjs`).
4. **لا تنتقل للمهام التالية قبل تحديد السبب أو إثبات أنه غير موجود في الكود مع تعليل.**

## 3) المهام بالترتيب (كل واحدة مع صورتها)

### المهمة 1 — الصفحة الرئيسية بالشكل المتفق (صور: `V-noir.png` `V-ivory.png` `V-nebula.png` `I2.png` `M.png`)
- بدون مشغّل: «مساء الخير / يومك» + ساعة كبيرة، بطاقتان (الصلاة القادمة والطقس)، ثم «ابدأ من حيث توقفت» بعنصرين.
- مع فيديو: بطاقة المشغّل = مصغّرة **16:9** يسار + شارة المصدر + عنوان + اسم القارئ/الفنان + شريط تقدم بالأوقات + أزرار (سابق/تشغيل/تالٍ)، وتحتها صف بطاقات (الصلاة · الطقس · البطارية).
- مع صوت: غلاف **مربع** + موجة صوتية + الباقي نفسه.
- **بلا دوائر أدوات** في الرئيسية (اللقطة والتسجيل والألوان والملاحظة السريعة والأوامر في صفحة «الالتقاط» فقط).
- حجم المصغّرة يتبع مقاس الجزيرة الذي يضبطه المستخدم (استعمل `thumbSize.ts`)، ولا شيء يتداخل.
- الملفات: `src/pages/island/Player.tsx` `IdleHome.tsx` `Pill.tsx` `island.css`. الاختبارات: `test:thumb` `test:idle` `test:dock`.

### المهمة 2 — الحبة: راحة ثم تمرير (صورة: `R.png`)
- راحة: مصغّرة 64×36 + اسم + موجة صغيرة، بلا أزرار.
- تمرير الماوس: تتمدد الحبة للأسفل بنابض (من `src/motion.ts`) فتظهر المصغّرة أكبر، وشريط التقدم بالوقتين، وأزرار السابق/التشغيل/التالي. الخروج يعيدها للراحة. لا شيء يتداخل. الشريط: ضغط/سحب للتقديم، والوقت المستهدف يظهر **داخل صف الأوقات** وليس فقاعة فوقه.
- لا تغيّر مقاسات الحبة/النظرة/اللوحة التي يضبطها المستخدم، ولا منطق `hit.rs`.

### المهمة 3 — الحجم العريض القصير (صورة: `U.png` الجزء السفلي)
- نقطة التبديل: ارتفاع اللوحة < 340 (`layoutMode.ts`).
- المشغّل بعرض كامل في الأعلى (مصغّرة 96×54 + عنوان + اسم + شريط + زر تشغيل)، وتحته **سطر واحد** (الصلاة · الطقس · البطارية)، ثم الدوك. لا عمود جانبي ولا خانة متبدّلة.

### المهمة 4 — إعداد «شكل شريط التقدم» (صور: `T.png` `U.png`)
- مفتاح جديد `progressStyle`: `line | shimmer | wave | liquid | dashes | ring`، الافتراضي `line`. مفتاحان إضافيان: `progressMotion` (bool، افتراضي true، ويحترم تقليل الحركة) و`progressScrubTime` (bool، افتراضي true).
- التطبيق: `<html data-pstyle="…">` يُضبط من `useSettings.ts` (أضفه داخل التأثير الموجود وتأكد أنه لا يكسر شيئًا)، والشكل بـ CSS على `.sk-track/.sk-fill/.sk-knob` في `island.css`:
  - `line`: خط رفيع + مقبض مضيء يكبر عند التمرير (الحالي).
  - `shimmer`: لمعان يمرّ كل 3 ثوانٍ + جزء المخزَّن + علامات الفصول.
  - `wave`: أعمدة موجة (القناع `repeating-linear-gradient`)، المشغَّل ذهبي.
  - `liquid`: تعبئة 9px برأس كرة مضيئة.
  - `dashes`: شرائح منفصلة.
  - `ring`: حلقة تقدم تلفّ زر التشغيل (تحتاج تعديل `Controls`).
- واجهة الإعداد: الإعدادات ▸ المشغّل، **بطاقات اختيار** بمعاينة لكل شكل كما في `U.png` (قائمة 2×3)، مع مفتاحي الحركة والوقت أثناء السحب. اختبار: `scripts/` جديد يتحقق من القيم الستة ومن أن الافتراضي `line` لا يغيّر الشكل الحالي.

### المهمة 5 — صفحة المظهر (صورة: `S.png`)
نفّذ **على ثلاث دفعات منفصلة** (commit لكل واحدة) واختبر بعد كل دفعة:
1. معرض الثيمات: قائمة/شبكة واحدة متتالية **بلا عناوين المجموعات** (ترتيب المجموعات الداخلي كما هو: seed ثم gradient ثم craft ثم editorial ثم shape ثم time ثم art ثم custom). البطاقات كما هي. اختيار ثيم يكتب `themePack` و`themePackLight` و`themePackDark` معًا.
2. حذف قسم «تعيين الحزمة» من الواجهة فقط (المفاتيح الثلاثة تبقى داخليًا للترحيل).
3. المواد: **مصمت** و**زجاج مثلّج** فقط. احذف أنماط «مدخّن» و«شفاف» و«داكن بسيط» من `STYLE_PRESETS` وبطاقة «زجاج مُحاكى — شفاف». القيمة المخزّنة `glassStyle: "clear"` تُعامل مثلّجًا بلا حذف المفتاح. **حدّث الاختبارات القديمة** (`scripts/glass.test.mjs` و`scripts/appearance.test.mjs` تتوقع 4 أنماط)، وشغّل `npm test` كاملًا قبل الدمج.
4. (بعد نجاح الدفعات) تبسيط الصفحة: 6 إعدادات أساسية (النمط، الثيم، لون التمييز، الزجاج، كثافة الخلفية، الحدود والظل) والباقي خلف «خيارات متقدمة» (الحزمة المخصصة، ثيماتي، تصدير/استيراد، الخط/الأيقونات).

### المهمة 6 — طابع «سديم» لكل الثيمات (صور: `N3.png` `V-nebula.png` `V-ivory.png` `V-noir.png`)
- لوحة الجزيرة: غسلتان متوهجتان بلون الثيم في زاويتين (أعلى-يسار وأسفل-يمين)، وتدرّج الأكسنت (`accent → accent2`) على: الدوك النشط، زر التشغيل، شريط التقدم، الفلاتر النشطة، الموجة.
- يُشتق من ألوان الثيم المختار نفسه (متغيرات `--accent` و`--t-wash-c` ونحوها)، وفي الوضع الفاتح بدرجة أخف. **بلا تغيير في بذور الثيمات.** العاجي: `#fbf7ee / #1d1b18 / #b85a2a`، وأسود ذهبي: `#16130f / #f3ece0 / #d9b46a`.

### المهمة 7 (اختيارية) — بقية «الأدوات والالتقاط والحافظة والتطبيقات»
بحسب `V-*.png`: الالتقاط (6 دوائر بمفاتيحها + الألوان المحفوظة)، الحافظة (بحث + فلاتر + عناصر)، التطبيقات (شبكة 4×2)، الأدوات (تبويبات فرعية + أشرطة موارد).

## 4) التحقق قبل كل commit (إلزامي)
```
npm run build
npm test                       # كل الاختبارات، وليس اختبارًا واحدًا فقط
cd src-tauri && cargo check    # على ويندوز، أو cargo check --target x86_64-pc-windows-gnu
```
- **شغّل `npm test` كاملًا دائمًا.** سبق أن فشل بناء النشر لأن اختبارًا لم يُشغَّل محليًا.
- لقطة Playwright لكل مهمة تُقارن بصورتها المرجعية (لوحة الرئيسية 560×360، العريضة 720×270).
- حدّث `docs/STATUS.md` (+ `IPC.md` و`MOTION.md` و`GLASS.md` عند الحاجة).

## 5) النشر
فرع ← PR إلى `main` ← دمج squash ← تشغيل workflow `build-windows.yml` بـ `workflow_dispatch` و`publish=true`. الإصدار `1.0.<رقم التشغيل>` والمحدّث يرتقي فقط (التراجع = نشر إصدار أحدث يلغي التغيير). **لا تنشر قبل نجاح البناء في Actions** (علامة خضراء)، وأرسل للمالك رقم الإصدار.

## 6) ما أريده منك في كل رد
بالعربية وبهذا الشكل فقط: **ما بُني (بالملفات) / كيف تحققت (نتائج الأوامر فعليًا) / ما تبقّى**. وإن لم تستطع فعل شيء فقل ذلك صراحة بدل ادعاء النجاح.
