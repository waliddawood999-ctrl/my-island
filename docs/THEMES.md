# THEMES — نظام الثيمات (حزم البذور اللونية)

> الكود: `src/themeEngine.ts` (المحرك الخالص) · `src/themePacks.ts` (الحزم) · `src/appearance.ts::deriveFor` (الربط بالإعدادات) · `src/tokens.css` + `src/pages/island/island.css` (الاستهلاك). الاختبارات: `scripts/theme.test.mjs` · `scripts/appearance.test.mjs`. جدول الحزم المولَّد: `node scripts/themes.report.mjs --write`.
> الزجاج (docs/GLASS.md) هو **المادة**؛ الحزم تركب فوقه ولا تستبدله: `glassTint` = شدة الحجاب، والعتامة من `glassAlpha`، ولا `backdrop-filter` في أي سطح.

## المبدأ المؤسِّس

لا خلفية كاملة التغطية أبدًا. الأسود المصمت «تمويه عتاد» لأجهزة النوتش لا قرار تصميمي، ولا ينتقل لحبة عائمة على ويندوز. كل حزمة = **3 بذور** (سطح + مقدمة + أكسنت) تُشتق منها كل الأسطح بلمسة لون وشكل فوق المادة. لا صور/ملمس كاملة التغطية، ولا خلفية لكل ودجت، ولا نص جسم بلون الأكسنت فوق المادة (الأكسنت للأيقونات والمؤشرات والنص الكبير فقط).

## خط الاشتقاق

`بذور (surface · fg · accent)` ← **كشف داكن/فاتح** (إضاءة نسبية البذرة < 0.179 = داكن؛ هي نقطة تساوي تباين الأبيض والأسود) ← **القاعدة المحايدة** ← **الرموز** ← **فرض المقروئية** ← متغيرات CSS على `<html>` (تصل كل النوافذ عبر `useAppearance`). حتمي بالكامل: نفس الدخل ⇒ نفس الخرج حرفيًا (`theme.test.mjs`).

| الخطوة | القاعدة (ثابتة في `themeEngine.ts`) |
|---|---|
| القاعدة المحايدة | OKLCH: كروما **0.008–0.015** نحو درجة بذرة السطح · إضاءة **14–18٪** داكن / **96–97٪** فاتح (تُقصّ إليها الإضاءة). **لا `#000` ولا `#fff` أبدًا** (اختبار) |
| المقدمة | لون المقدمة = بذرة `fg` (تُستبدل بالافتراضية إن عاكست الوضع). كل رمز نص = المقدمة بـ**ألفا مثبّتة** (جدول أدناه) |
| الأسطح | **خلط خطي** (sRGB) للقاعدة نحو المقدمة بمعاملات مثبّتة: بطاقة 5٪/4٪ · مرفوعة 9٪/7٪ · hover +8٪/+7٪ · active +14٪/+12٪ · قوي 20٪/17٪ (داكن/فاتح) — «بطاقات كدرجات إضاءة» |
| الغسلة الاتجاهية | لون الأكسنت بسقف **14٪ داكن / 10٪ فاتح** × شدة الحزمة (0..1)، تتلاشى إلى **صفر عند 60٪ ارتفاعًا** (`transparent 60%`)؛ الاتجاه: أعلى/أسفل/بداية/نهاية/شعاعي أو شبكة (Mesh) من لونين |
| توهّج المرساة | يلتف حول الحبة: سقف **20٪**، تمويه **≥ 48px** (56px مُنفَّذة)، خارجي + داخلي (نصف الشدة). يُطفأ في Eco |
| الزخرفة المقصوصة | اختيارية **4–8٪** داخل الرصّة، مقصوصة بشكل الجزيرة (`border-radius: inherit`) — ليست صورة كاملة التغطية |
| الحبيبات | حتى **8٪** (الافتراضي 3.5٪)؛ ثابتة بلا حركة |
| الحدّ | **1px** بنسبة **6–10٪** من لون المقدمة (`borderStrength` 0 ⇒ بلا حدّ، 1..100 ⇒ 6..10٪) + **حافة علوية لامعة** (`--glass-spec`: 22٪ داكن / 85٪ فاتح) |

### ألفا المقدمة المثبّتة (`FG_ALPHA`)

| الرمز | داكن | فاتح |
|---|---|---|
| نص أساسي | 1.00 | 1.00 |
| نص ثانوي | 0.70 | 0.68 |
| نص ثالثي | 0.52 | 0.58 |
| hover / active / قوي | .08 / .14 / .20 | .07 / .12 / .17 |
| بطاقة / مرفوعة | .05 / .09 | .04 / .07 |
| لمعة الحافة العلوية | .22 | .85 |

### فرض المقروئية (WCAG)

القياس على **أسوأ سطح خلف النص**: القاعدة · قمة الغسلة (القاعدة + الأكسنت بسقف الغسلة) · بطاقة مرفوعة فوق قمة الغسلة.

- **نص** (أساسي/ثانوي/ثالثي) ≥ **4.5:1**: الألفا المثبّتة تُرفع بخطوة .02 حتى تجتاز.
- **أكسنت** (أيقونات/مؤشرات/نص كبير) ≥ **3:1** على أسوأ سطح: تُفتَّح/تُغمَّق **إضاءته في OKLCH بنفس الدرجة والكروما** (خطوة .015) حتى يجتاز.
- **onAccent** = الأعلى تباينًا بين أبيض وحبر داكن فوق الأكسنت (رياضيًا ≥ 4.58 دائمًا) ⇒ نص الأزرار ≥ 4.5.
- **ألوان الحالة** (نجاح/تحذير/خطر/معلومة) ≥ 4.5:1 بالطريقة نفسها.
- **كل تعديل آلي يُسجَّل** `{token, from, to, reason, before, after}` ويُسرد بشفافية في الإعدادات (المظهر ← إمكانية الوصول) عبر `describeAdjustment`.
- أرضية **Luma** (Living Artwork فقط): تُقلَّل **الغسلة** (×0.9 حتى تجتاز) بدل رفع الألفا، فيبقى النص بألفاته المثبّتة.

### مصادر الأكسنت (`accentSource`)

`pack` (بذرة الحزمة، الافتراضي) · `custom` (`accentColor`) · `windows` (أكسنت ويندوز الحي) · `wallpaper` (لون الخلفية الغالب). المصادر الخارجية اختيارية وصريحة ومحلية بالكامل (لا رفع)، وفشلها يسقط صامتًا إلى بذرة الحزمة. المستخدمون الذين اختاروا لونًا ثابتًا قبل هذا النظام يُرحَّلون إلى `custom` (لا يتغيّر لونهم).

### التبديل والحركة

كل لون رصّة يمر عبر متغيرات مسجّلة (`@property` في `tokens.css`: `--glass-base` `--t-wash-*` `--t-glow-*`) فيتلاشى عند تبديل الحزمة/الغلاف بمدة `--theme-fade` = `dur.theme` من `src/motion.ts` (600ms عند السرعة 1، 200ms في reduced، 0 في off) — **لا مدد خارج ثوابت الحركة**. لا rAF ولا مؤقّتات في الخمول (التلاشي انتقال CSS).

## حزم العائلة (أ) — مشتقة من بذور (التسع)

Obsidian (افتراضية رائدة) · Aurora (مخضّر ← بنفسجي بشبكة Mesh) · Ember (كهرماني يتوهّج من الأسفل) · Sakura Veil (وردي مُخفّت) · Evergreen Mist (أخضر بضباب شعاعي) · Ultraviolet (تدرّج + حبيبات 7٪) · Porcelain (فاتح أولًا) · Windows Mirror (البذرة = أكسنت ويندوز الحي) · Living Artwork.

### Windows Mirror
`system_accent` يقرأ `HKCU\Software\Microsoft\Windows\DWM\AccentColor`؛ يصير أكسنت الحزمة، وبذرة السطح تُمزج 10٪ منه (قبل القاعدة المحايدة). بلا قيمة ⇒ بذرتها `#0078d4`.

### Living Artwork
من غلاف الوسائط الجارية فقط (`media_now` + `media:cover`، يُفكّ إلى 40×40 مرة لكل تبدّل ثم يُحرَّر — `useSettings::useArtworkSwatches`، ولا يعمل إلا إن اختيرت الحزمة): `artwork.ts::extractSwatches` يعيد Vibrant / DarkMuted / Muted. **غسلة = DarkMuted · توهّج وأكسنت = Vibrant**.
- **مقياس الإزهار** `artBloom` 0–200٪ (افتراضي **60**): يضرب سقف الغسلة والتوهّج (100٪ = سقوف الرصّة؛ 200٪ = ضعفها — الحزمة الوحيدة التي يُسمح لها بتجاوز السقف، بطلب المرجع الملزم).
- **أرضية المقروئية (Luma)**: تُقلَّل الغسلة (×0.9) حتى يجتاز النص بألفاته المثبّتة، فالإزهار 200٪ لا يكسر القراءة حتى لغلاف أبيض/أصفر ساطع (مُختبَر).
- **بلا وسائط** (أو غلاف رمادي بلا سواتش) ⇒ تسقط صامتةً إلى Obsidian (`effectivePack`).
- **التلاشي المتقاطع 600ms** = `dur.theme` (motion.ts) عبر متغيرات `@property` المسجّلة؛ في reduced 200ms وفي off فوري.

### مصادر الأكسنت الإضافية
`wallpaper_color`: مسار الخلفية من النظام ← مصغّرة 64px محليًا ← لون غالب (صناديق 4 بت، الوزن = العدد × (0.25 + التشبّع)، يتجاهل الأسود/الأبيض القريبين) ← كاش بالمسار + وقت التعديل، سقوط صامت. **لا رفع خارجي، واختياري وصريح.**

### الحزمة المخصصة وحزم المستخدم
بذور المستخدم **(أكسنت + شدة صبغة + توهّج + اتجاه غسلة + حبيبات)** ضمن نطاقات مصمَّمة: صبغة 0–1 · توهّج 0–1 · حبيبات 0–8٪ · اتجاه ∈ {أعلى، أسفل، بداية، نهاية، شعاعي} · أكسنت أي لون (يفرض المحرك تباينه). `sanitizeUserTheme` يقصّ المدخلات (وكذلك المستوردة من JSON) ويسقط غير الصالح، والاختبار يجرّب **كل التوليفات القصوى** (أكسنت أبيض/أصفر/أسود/أخضر فاقع × 4 قواعد × داكن/فاتح × صبغة وتوهّج وحبيبات في أقصاها) فتبقى كل أدوار WCAG ناجحة ⇒ يستحيل إنتاج ثيم كاسر للمقروئية. **حزم المصنع لا تُعدَّل أبدًا**: تخصيصها يولّد نسخة (`userPack`) تُخزَّن في `themeCustom` (خانة التعديل الحيّة، المعرّف `custom`) أو `myThemes` (رفّ «ثيماتي»، المعرّف `u:xxxx`).
